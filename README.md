# YesDetail
상품 상세페이지 제작 및 캡처 편집 도구.

## 로컬 실행
Node.js 20 이상에서 `npm start` 실행 후 http://127.0.0.1:4173 접속.
API 키는 저장소에 포함하지 않습니다. Gemini 설정은 로컬 연결 실행 파일을 사용하세요.

## 웹 배포
정적 화면은 GitHub Pages에서 실행할 수 있습니다. AI 분석·사진 검색 등 서버 API 기능은 별도 서버가 필요하며 Pages만으로 동작하지 않습니다.
기존 개인 프로젝트, 자동 저장 데이터, API 키와 사용량 기록은 배포본에 포함하지 않았습니다.
