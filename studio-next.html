AI 연결 설정

소스 폴더의 AI 연결 실행.cmd를 실행하고 API 키를 입력하세요. 키는 서버 메모리에만 보관하고 종료하면 지웁니다. 채팅이나 프로젝트 파일에 키를 넣지 마세요.

  1. Google AI Studio에서 API 키 발급
  2. 결제 계정이 연결되지 않은 Free tier 프로젝트인지 확인합니다. 카드 등록·유료 업그레이드는 하지 않습니다.
  3. AI 연결 실행.cmd에서 1(Gemini) 또는 3(둘 다)을 선택합니다.
  4. 무료 프로젝트 확인 후 FREE를 입력하고 키를 붙여넣습니다(화면에 표시되지 않음).
  5. 이 화면에서 연결 상태 확인을 누릅니다.

선택한 무료 모델만 호출합니다. 한도 오류면 다음 Google 일일 초기화까지 중지하고, 혼잡·시간 초과 후에는 2분간 대기합니다. 자동 재시도·유료 전환 없음. 일일 안전 제한 6회, 최소 간격 60초이며 실패도 포함합니다. 사용 기록은 서버 재실행 후에도 유지됩니다. Google 실제 무료 한도는 AI Studio에서 별도 확인하세요.

API 키만으로 Google의 결제 연결 여부를 자동 확인할 수 없습니다. 유료 프로젝트 키를 넣으면 과금될 수 있으므로 결제 미연결 프로젝트만 사용하세요. 무료 데이터는 Google 제품 개선에 사용될 수 있습니다.

OpenAI GPT-5.6 Terra는 별도 유료 선택입니다. 서버에서 PAID 확인과 키 입력 후, 생성할 때도 직접 유료 요청을 확인해야 합니다. Gemini 실패 시 자동으로 사용하지 않습니다.

상품명·입력 정보·선택 사진 최대 3장의 1,024px 이내 축소 사본만 선택한 서비스에 전송합니다. 원본 사진은 보존됩니다. AI는 사진을 새로 생성하지 않으며 원본 사진과 편집 가능한 문구로 디자인을 구성합니다.
